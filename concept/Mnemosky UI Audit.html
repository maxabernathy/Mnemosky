The Observatory

02 / 06 · one shell · four modes · one grammar
Mnemosky is an instrument for finding dim signal in noisy sky.

At the desk it is a Python tool; in the gallery it is a telescope the room looks through — a machine whose thinking is always visible. The shell makes the thinking visible: the Ledger always ambient, the observer always named, the model always learning in public.
pillar · 01

One shell, four modes

Tune · Observe · Review · Inspect. Every surface in v0.2 maps cleanly to one. Mode-switch is a single keystroke; the frame stays, the sidebar reconfigures. Visitors cycle 1–2–3–4 and never leave the world.

pillar · 02

The Ledger is always visible

A live ribbon of the Translation Ledger lives under every frame. Seven rejection categories, counted in real time. Tap a category and the canvas dims to only that kind of rejection — the STS spine becomes an ambient material.

pillar · 03

Observer card, not observer flags

Latitude, longitude, Bortle, FOV and free-text notes collapse into a single card in the top bar. Haraway's situated knowledge made a literal object. At 8K it reads from four metres as a quiet sentence, not a metadata dump.

pillar · 04

Organic feedback, scientific data

Mercury-blob loaders appear only at thresholds — loading, saving, "learning…", Tier-2 passes. Between thresholds the UI stays geometric. The instrument's slow thoughts are organic; its fast answers are precise.

Attract loop & room adaptation

05 / 06 · continuous observation, not a looped video
The room never plays a tape. A real detection run is always running; the display shifts what it shows the room depending on who's standing in front of it and what time it is.

The Ledger ribbon glows once. Continuous observation resumes. The visitor who just walked up sees a telescope, not a title card.

room sensor · presence
Attract ↔ engage

Empty room: meditative loop, large type, long holds. Visitor within 2 m: sidebar dilates, keyboard cheatsheet appears on the console, Observe becomes interactive.

time of day
Dusk colour-shift

Gallery light shifts the grass-bokeh background 6 % warmer at dusk, 4 % cooler at noon — imperceptible per-minute, beautiful across an afternoon.

docent takeover
Operator key

A hardware key on the console switches to docent mode: full four-mode control, pinned detections become a slideshow, room goes quiet while the docent narrates.

Delivery · from concept to gallery

06 / 06
phase · 01

Ratify the shell

This document. Once the shell grammar (Tune · Observe · Review · Inspect + Ledger ribbon + Observer card) is agreed, everything else follows. Full-fidelity mockups of the other three modes next.

phase · 02

Port theme into OpenCV

The warmer palette, mono + italic-serif type pairing, Ledger ribbon and Observer card can all land inside the current OpenCV shell for v0.3.x — no framework migration required.

phase · 03

Gallery build · Qt or web

Review and Inspect want richer interaction than OpenCV provides at 8K. A minimal Qt/PySide or web shell wraps the existing detector as a service; the museum build is an instance of that shell with room-sensor adapters.

hardware

8K · 2–4 m · capacitive console

Single 8K panel (85"+), wall-mounted, capacitive touch console at standing height for Tune/Review/Inspect. Room presence sensor optional but recommended for the adaptive loop.

content pipeline

Live + greatest-hits

One stream is a live re-processing of a prepared corpus (Radon + NN hybrid). A second stream is the HITL "greatest hits" — replayed human corrections that train the model on camera.

open questions

What we still need

Venue dimensions & ambient light spec · confirmed corpus of footage · docent script language · decision on Qt vs. web · hardware budget for the 8K + console + sensor trio.
